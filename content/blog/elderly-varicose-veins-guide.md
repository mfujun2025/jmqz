## 为什么老年人要单独讲一次

下肢静脉疾病在老年人身上，不是"年轻人的病加了个岁数"这么简单。

先看几组数据。据我国流行病学调查，**下肢静脉疾病患病率约为 8.89%**，患者近 1 亿，每年新发病率 0.5%~3.0%，其中静脉性溃疡约占 1.5%。而年龄是最明确的推动因素之一——**60~80 岁是慢性静脉疾病（CVD）患病率的峰值年龄段**；到了 65 岁以上，**下肢静脉性溃疡的患病率是总体人群的 3~5 倍（3%~5%）**。

这些数字来自《老年人慢性静脉疾病诊治中国专家共识》（中国老年医学学会周围血管疾病管理分会，2025 年）。这也是我国第一部专门针对 60 岁及以上人群的慢性静脉疾病共识，它反复强调一件事：**老年患者的诊疗策略不能简单照搬通用指南。**

原因很实在——老年患者往往同时存在几个状况：症状感知变迟钝、合并症多、同时在吃好几种药、皮肤和血管都更脆弱。这四点叠在一起，就出现了那句临床上的老话：**同样的曲张，老年人更容易拖到并发症才来。**

> 这篇文章的重点不是"教你自己判断"，而是帮老人和家属理清两件事：**哪些情况必须先让医生排除动脉问题，以及弹力袜在什么情况下能穿、什么情况下绝对不能穿。**

## 一、老年人静脉曲张的四个特殊之处

### 1. 症状不典型，容易被"归到老了"

年轻人腿胀会明确说"我腿不舒服"，老年人不一样：

- **疼痛感知下降**——静脉高压引起的酸胀、沉重感可能被忽略或被当成"腿脚不灵便"
- **容易被归因错**——腿沉、走不动被当成腰椎间盘突出、关节退变、单纯"人老了"
- **主诉集中在"肿"和"抽筋"**——夜間小腿抽筋、下午脚踝肿，是最常被忽略的早期信号

结果就是就诊时间被往后推。而慢性静脉疾病是**进展性**的，拖到皮肤色素沉着、脂质硬化、溃疡这一步，处理难度和费用都会明显上升。

### 2. 合并症多，症状很容易"串味"

老年人常常不止一种病，而好几种病都会让腿肿：

| 腿肿的可能原因 | 特点 | 该怎么查 |
|---|---|---|
| 下肢静脉疾病（静脉曲张/静脉功能不全） | 久站久坐后加重、抬高患肢能缓解 | 下肢静脉超声 |
| 心功能不全 | 双下肢对称水肿，常伴气短、夜间憋醒 | 心脏超声、BNP 等 |
| 肾功能不全 | 水肿常伴眼睑浮肿、尿检异常 | 尿常规、肾功能 |
| 下肢动脉硬化闭塞症 | 腿凉、走一段路就小腿疼、休息能缓解 | 踝肱指数（ABI）、动脉超声 |
| 药物性水肿 | 某些降压药、激素等可引起 | 由医生核对用药清单 |

这也是共识特别强调的：老年患者的评估要**同时看下肢动脉病变、出血风险、系统性疾病和用药情况**，而不是只盯着腿上的血管。

### 3. 皮肤更脆弱，并发症更重

老年人皮肤弹性下降、皮下脂肪变薄，同样的压力，年轻人穿没问题，老人可能就压出红斑甚至破损。而一旦皮肤破溃，老年患者愈合更慢、感染风险更高。

### 4. 用药和麻醉风险都更高

肝肾功能随年龄生理性减退，药物代谢和排泄变慢，**常规剂量有可能蓄积**；加上多重用药，药物相互作用的风险明显升高。这些都会影响治疗方案的选择。

## 二、最要紧的一步：先分清是"静脉"还是"动脉"

这一个问题，比后面所有内容都重要。因为它直接决定——**弹力袜能不能穿。**

### 1. 为什么这个区分是"生死线"

静脉曲张是**血液回不去**，压力治疗（弹力袜）是"从外面帮一把"，把血往上推。

但下肢动脉硬化闭塞症是**血液进不来**。这时候再给腿加外部压力，相当于在已经狭窄的供血通道外面又套了一层挤压——**可能让本来就缺血的腿更缺血。**

文献里有一句说得很直白：**动静脉病变同时存在，是老年人弹力袜处方失败的常见原因。** 有资料显示，约 **20% 的静脉性溃疡患者同时存在动脉疾病**；而我国老年人群中下肢动脉硬化闭塞症的患病率在 10% 以上。也就是说，老年人里"既有静脉问题、又有动脉问题"的比例并不低。

### 2. 三条可以自己先留意的线索

下面这个对照表，家属可以帮老人对着看。**注意：它只用于"提醒你去查"，不能用来自己下诊断。**

| 观察点 | 更像静脉问题 | 更像动脉问题 |
|---|---|---|
| 腿的外观 | 青筋凸起、迂曲成团、皮肤色素沉着 | 皮肤苍白、发亮、汗毛脱落、趾甲变厚 |
| 腿的温度 | 多为正常或偏热 | 明显发凉，双侧不对称 |
| 不适出现时机 | 久站久坐后加重，抬高腿可缓解 | **走路一段距离后小腿疼，停下休息能缓解**（间歇性跛行） |
| 抬高腿的反应 | 抬高后肿胀减轻、感觉舒服 | 抬高后反而更疼 |
| 疼痛特点 | 酸胀、沉重、抽筋 | 刺痛、夜间静息痛，严重时足趾发黑 |

> **一个特别容易踩的坑**：如果老人**抬高腿以后腿更疼**，或者**走几百米就必须停下来歇**，那要先按动脉问题去查，**不要急着买弹力袜**。

### 3. 踝肱指数（ABI）：一个简单的门诊检查

能不能安全加压，临床上有个客观指标——**踝肱指数（ABI）**，就是脚踝动脉收缩压除以手臂肱动脉收缩压。检查无创、几分钟完成，很多医院血管外科门诊就能做。

| ABI 数值 | 含义 | 加压治疗 |
|---|---|---|
| 0.9~1.3 | 正常范围 | 可以加压 |
| 0.8~1.0 | 轻度下肢动脉病变 | 谨慎加压，需医生评估 |
| 0.6~0.8 | 明显下肢动脉病变 | 需改用减压方案，并转诊血管专科 |
| < 0.6 | 严重下肢动脉缺血 | **不宜常规加压** |
| < 0.5 | 严重缺血 / 肢体威胁 | **不加压，尽快转诊血管专科** |
| > 1.3 | 提示血管壁钙化、血管失去收缩功能 | 数值可能"假性偏高"，需进一步评估 |

ABI 诊断下肢外周动脉疾病的敏感性和特异性分别可达 95% 和 99%，是目前公认的**首选无创筛查指标**。

> **老年人和家属要特别记住一条**：**糖尿病、慢性肾病（尤其透析）的老人，血管壁常有钙化，ABI 可能测出"假性正常"甚至偏高。** 所以数值正常不等于绝对安全，有疑问时医生还会加做趾端压力、动脉超声等检查。

## 三、什么情况下绝对不能穿弹力袜

压力治疗是慢性静脉疾病治疗体系里的基础一环，但它有明确的禁忌。《老年人慢性静脉疾病诊治中国专家共识》列出了**绝对禁忌证**：

| 绝对禁忌证（不宜加压） |
|---|
| 踝肱指数 < 0.6 的严重下肢动脉缺血性疾病 |
| 拟加压部位存在血管转流通道 |
| 美国纽约心脏病协会（NYHA）**Ⅳ 级**心力衰竭 |
| 对加压材料严重过敏 |
| 伴有感觉丧失的严重糖尿病神经病变，或伴有皮肤坏死风险的微血管病变 |
| 严重下肢蜂窝织炎 |
| 肢体重症感染未得到有效控制 |

此外，还有几类属于**慎用、需严密监测**的情况：

- 轻中度下肢动脉缺血（ABI 0.5~0.8）
- NYHA **Ⅲ 级**心力衰竭
- 糖尿病足（如需使用，优先选开口型，并每日观察血运）
- 凝血功能障碍、出血风险高者
- 下肢重度水肿（通常先消肿再重新评估）

> 这条红线值得家属记牢：**"静脉曲张"这个诊断本身，不代表一定能穿弹力袜。** 老年人开穿之前，先让医生看一眼动脉情况——这一步省不得。

## 四、老人穿弹力袜，怎么穿才安全

如果医生评估后认为可以加压，那具体怎么穿，也跟年轻人不一样。共识针对老年患者给出了几条明确建议。

### 1. 首选膝下长度

共识推荐**首选膝下长度的医用弹力袜**。原因是老年人穿脱能力相对较弱、对压力耐受较差，膝下款比大腿款、连裤款更容易穿、也更容易坚持。

### 2. 必要时适当降低压力等级

共识明确提出：**依据个体情况适当降低压力等级**。老年人皮肤弹性差、皮下脂肪少，压力过高容易造成皮肤损伤。所以"越紧越有用"这个想法在老人身上是不成立的——**压力应该由医生根据分级和耐受度来定，不是越高压越好。**

### 3. 借助穿脱辅助装置

手部力量减弱的老人，自己把弹力袜拉上去是很费劲的，硬拽还容易损伤皮肤。可以：

- 使用**弹力袜穿脱辅助器**（套筒式、滑板式等）
- 由家属协助穿戴，尤其是清晨刚起床、腿还没肿的时候穿
- 剪短指甲、摘掉戒指，避免勾破袜子或划伤皮肤

### 4. 每天检查皮肤，这一步不能省

共识强调，压力治疗期间**需密切监测加压部位的皮肤状况和血液循环变化**。家属可以每天帮老人看一遍：

- 脚踝、脚背有没有**压痕过深、红斑、水疱、破损**
- 脚趾颜色、温度有没有变化
- 有没有**发麻、刺痛、脚趾发凉**（可能提示血运受影响）
- 皮肤有没有瘙痒、起疹（可能对材料过敏）

出现上述任何一条，**先停穿并联系医生**，不要硬撑。

### 5. 穿不下去怎么办：还有替代方案

如果老人实在耐受不了持续加压，共识指出**间歇性充气加压治疗（IPC）**可以作为替代方案——通过周期性充气和放气模拟小腿肌肉泵，促进血液回流。它通常在医疗机构或按医嘱居家使用，属于器械治疗，需由医生评估后决定。

> 再强调一次定位：**弹力袜是物理干预手段和辅助措施，不能替代药物，也不能替代手术。** 它能帮助缓解症状、延缓进展，但不解决已经发生的瓣膜结构问题。

## 五、老人的用药：多重用药下的三条注意

静脉活性药物（如微粒化纯化黄酮类、七叶皂苷类、香豆素类、马栗种子提取物、羟苯磺酸钙等）是慢性静脉疾病的常用辅助手段，共识推荐**至少使用 3~6 个月**，可以改善症状并促进溃疡愈合。

但在老年人身上，用药要多想一层：

1. **剂量需要调整**——老年患者肝肾功能生理性减退，药物代谢动力学改变，**需根据肾功能调整剂量**，不能直接照搬成人常规剂量。
2. **警惕药物相互作用**——多重用药现象普遍。老人如果正在服用抗凝药、抗血小板药、降压药、降糖药，加用任何新药前都要让医生把所有在吃的药一起过一遍。
3. **别自己加、别自己停**——症状缓解了就自行停药，或者听人推荐就买来吃，这两种都很常见，也都有风险。

> **须由医生评估，不可自行购买服用。** 尤其是合并肝肾功能不全、心功能不全，或正在服用抗凝药的老人，用药方案必须由医生面诊后决定。

## 六、老年人能不能手术？怎么选

能，但选择逻辑和年轻人不同。共识的取向很明确：**在老年患者中优先考虑创伤小的方案。**

### 1. 什么情况下考虑手术

共识列出的浅静脉功能不全手术指征包括：

- 存在轴性反流的隐静脉
- 出现明显的静脉曲张
- 因久站久坐引发疼痛、沉重感等不适症状
- 发生浅表静脉血栓形成或复发性静脉炎
- 静脉曲张破裂出血
- 出现皮肤并发症（色素沉着、湿疹、皮肤硬化、静脉性溃疡）

### 2. 微创优先

- **推荐微创术式**——腔内热消融（射频消融、腔内激光闭合）、腔内化学消融（硬化剂注射、静脉腔内黏合剂闭合）、机械化学消融等，创伤小、恢复快
- **开放手术**（隐静脉高位结扎加抽剥术）应**严格限制适应证**，因为老年患者肌肉等软组织萎缩会造成解剖变异，邻近神经损伤的风险更高
- **麻醉**方面，共识推荐**肿胀麻醉**，以减少老年患者的麻醉风险

### 3. 术前必做的评估

老年患者手术前，医生会综合评估**预期寿命、手术耐受性、获益与风险比**，并充分告知患者及家属。还要提醒一点：共识指出**术后压迫治疗的压力应适宜并相对缩短时间**，以减少老年患者的局部并发症风险。

## 七、日常在家能做的六件事

这几条都出自共识的生活方式与物理治疗建议，家属可以照着执行：

| 项目 | 具体要求 |
|---|---|
| 抬高患肢 | 平卧时抬高患肢至**高于心脏水平**，每日 **≥3 次**，每次 **≥30 分钟** |
| 规律运动 | **以散步为主**；身体条件许可时，可结合有氧运动、力量训练、伸展运动。一般建议**每周至少 3 次、每次 30 分钟以上** |
| 避免久站久坐 | 每 30~60 分钟起身活动一次 |
| 控制体重 | 减轻体质量，降低下肢静脉压力 |
| 避免热暴露 | 减少长时间热水泡脚、热敷、桑拿等热暴露 |
| 皮肤护理 | 保持清洁、适度保湿，**避免搔抓**，防止破损感染 |

### 关于"泡脚、热敷"这件事

很多老人晚上喜欢用热水泡脚缓解腿胀，家属也常觉得这是好事。需要分情况说：

- **单纯静脉问题**：长时间高温热暴露会让血管扩张、组织渗出增加，可能**加重水肿和沉重感**，共识把"避免热暴露"写进了生活管理建议里
- **合并动脉缺血**：热敷、烫脚可能**加重缺血性疼痛**，属于明确的禁忌做法

所以，泡脚这件事在老年静脉曲张患者身上，**建议先问过主诊医生**，不要当作默认的"保养手段"。

### 深呼吸训练：一个容易被忽略的小方法

共识还提到，**深呼吸训练可以增加胸腔负压，促进静脉回流**，有助于减轻慢性静脉疾病引起的疼痛和水肿。对老年人来说，这是一个零成本、无负担的辅助动作，可以每天做几组。

## 八、家属能做的三件事

1. **提醒筛查**：共识建议对老年人群进行**定期慢性静脉疾病筛查**，尤其是**有家族史、肥胖或长期久坐习惯**的高风险个体。别等腿上出现溃疡才去查。
2. **帮着穿、帮着看**：协助穿戴弹力袜，并每天检查小腿、脚踝、脚背的皮肤和血运变化。
3. **管好用药清单**：把老人在吃的所有药（包括保健品）列一张清单，每次就诊都带上，让医生评估相互作用。

## 常见问题

### Q1：老人说"不疼不痒，不用管"，对吗？

要看情况。C0~C1 级、没有明显体征的患者，医生可能建议以生活方式调整和压力治疗为主，**定期观察**。但"不用管"意味着**不再复查**，这就错了——慢性静脉疾病是进展性的，而且老年人疼痛感知迟钝，等到自己觉得难受时，往往已经出现了皮肤改变。**该查的要查，该复查的要复查。**

### Q2：弹力袜要穿一辈子吗？

没有统一答案，取决于分级、治疗方式和医生方案。多数情况下压力治疗是长期手段，但**压力等级、穿着时长（是否白天穿、夜间脱）需要按阶段调整**，由医生根据复查结果决定，不是一成不变。

### Q3：老人有高血压、心脏病，还能穿吗？

不能一概而论。**NYHA Ⅳ 级心力衰竭属于压力治疗的绝对禁忌证**，Ⅲ 级属于慎用；高血压本身如果控制平稳，通常不影响加压。**结论只有一句：让医生评估心功能和动脉情况后再决定。**

### Q4：腿上皮肤发黑、发痒，抹药膏行吗？

**先别自己抹。** 皮肤色素沉着、湿疹样变是慢性静脉疾病的 C4 期表现，根子在静脉高压，单靠外用药膏解决不了问题，不恰当的药膏还可能刺激皮肤。建议直接到**血管外科**就诊。

### Q5：静脉活性药物能长期吃吗？

共识推荐静脉活性药物**至少使用 3~6 个月**，对改善症状、促进溃疡愈合有帮助。但老年人肝肾功能减退，**需根据肾功能调整剂量**。是否长期使用、用哪一种、剂量多少，**须由医生评估，不可自行购买服用**。

## 给老人和家属的一句话总结

老年静脉曲张，关键不是"穿不穿弹力袜"，而是**先搞清两件事**：

1. **动脉通不通**——先看有没有间歇性跛行、腿凉、抬腿更疼这些线索，必要时查一次**踝肱指数（ABI）**。ABI < 0.6 属于压力治疗的绝对禁忌。
2. **身体扛不扛得住**——合并心衰、糖尿病、肾病，或同时在吃多种药的老人，方案要个体化，微创优先，压力等级适当降低。

能穿的话，记住三件事：**膝下长度优先、压力由医生定、每天检查皮肤。**

> 本文仅供健康科普参考，不构成诊疗建议。如有相关症状，请及时到正规医院血管外科就诊。老年患者常合并心、肾、动脉等多种疾病，具体方案以医生面诊意见为准。
