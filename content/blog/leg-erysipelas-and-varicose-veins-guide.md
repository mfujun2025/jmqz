## 小腿突然红了一片，还发起烧来

一位静脉曲张十几年的读者曾经描述过这样的经历：某天下午，他发现左小腿内侧多了一块巴掌大的红斑，皮肤发烫、发亮，走路时火辣辣地疼。到了晚上，他开始打寒战，体温升到 39℃。他以为是"静脉曲张加重了"，自己用热水泡了脚，又拿按摩仪推了半小时。第二天，红斑扩大了一倍。

这个场景在血管外科和皮肤科并不少见。**静脉曲张患者腿上出现红肿热痛，未必是静脉曲张本身加重，也可能是细菌感染——丹毒或蜂窝织炎。** 这两类问题的处理方向完全不同：一个以改善静脉回流为主，一个必须尽快抗感染。用错方法，可能让感染扩散。

这篇文章讲清三件事：丹毒是什么、静脉曲张的人为什么更容易得、以及出现哪些信号必须马上就医。

## 一、丹毒是什么？它和静脉曲张是什么关系

### 丹毒是细菌进入了皮肤浅层和淋巴管

丹毒是一种急性皮肤感染。它主要累及真皮上层和皮肤淋巴管，致病菌以 A 组β溶血性链球菌为主，B 组、C 组、G 组链球菌也可引起。金黄色葡萄球菌相对少见（Jaskóła-Polkowska 等）。

细菌不会凭空进入皮肤。它需要一个"入口"。常见的入口包括：

- 足癣造成的趾间浸渍、皲裂
- 甲癣（灰指甲）周围的皮肤破损
- 小腿皮肤干燥皲裂、湿疹抓痕
- 蚊虫叮咬后被抓破
- 下肢静脉性溃疡的创面
- 轻微擦伤、手术切口

腾讯医典的丹毒条目把"下肢静脉曲张"明确列为危险因素之一，把足癣、趾甲真菌病、皮肤溃疡、慢性湿疹列为常见诱因（该条目由西安市第九医院皮肤科李岚岚主治医师撰写、白求恩国际和平医院皮肤科褚京津主任医师审阅）。

### 静脉曲张为什么成了"帮凶"

静脉曲张本身不产生细菌，但它会一步步把皮肤变成"容易破、破了难长好"的状态。这条链条大致是这样的：

**静脉压长期偏高 → 足靴区皮肤营养障碍 → 淤积性皮炎、色素沉着、皮肤变硬变薄 → 干燥、脱屑、瘙痒 → 抓破或皲裂 → 细菌从破口进入 → 丹毒 → 淋巴管受损 → 淋巴水肿 → 更容易再次感染。**

科普中国刊载的科普文章对这条链条有一段很直白的描述：足靴区皮肤因营养性变化发生变性而形成皮炎，出现脱屑、瘙痒，局部抵抗力薄弱，承受慢性感染，可并发湿疹、丹毒、淋巴管炎；反复多次发作后，淋巴管阻塞又续致淋巴水肿（《下肢静脉曲张炎变综合征是一场"瘀"与"湿热"的持久战争》，科普中国网）。

腾讯医典的淤积性皮炎条目（由四川大学华西医院皮肤科文翔副主任医师审阅）也指出，淤积性皮炎好发于静脉曲张者的足靴区，表现为红斑、水肿、瘙痒、丘疹，搔抓后糜烂渗出，皮肤粗糙脱屑；病情迁延可形成慢性溃疡，而"严重感染"被列为该病的并发症之一。

换句话说，**静脉曲张给细菌准备好了一块"门户大开"的皮肤**。这也是为什么同样是被蚊子咬一口，静脉曲张患者更容易出现红肿蔓延。

## 二、一张表分清：丹毒、蜂窝织炎、静脉炎、淤积性皮炎

小腿红肿的病因不止一个。下面这张表把四种常见情况放在一起对照，但请记住：**表格只能帮你建立方向感，不能替代医生的面诊判断。**

| 对比项 | 丹毒 | 蜂窝织炎 | 血栓性浅静脉炎 | 淤积性皮炎 |
|---|---|---|---|---|
| 病变位置 | 真皮上层与皮肤淋巴管 | 更深的皮下组织 | 浅静脉血管壁，常伴血栓 | 足靴区皮肤全层 |
| 边界 | 清楚、略隆起，像"地图边" | 不清、弥漫 | 沿静脉走行呈条带状 | 弥漫，边界模糊 |
| 颜色与表面 | 鲜红、发亮、紧绷 | 暗红，可有橘皮样外观 | 沿血管走行的红斑 | 红斑、褐色色素沉着、脱屑 |
| 触感 | 皮温高，按压后红色可暂时消退 | 皮温高，可有凹陷 | 可摸到条索状硬结 | 皮肤粗糙、增厚 |
| 疼痛 | 灼痛、触痛明显 | 胀痛，化脓时跳痛 | 沿血管走行的触痛 | 以瘙痒为主，抓破后疼痛 |
| 全身症状 | 常有高热、寒战，体温可达 39℃ 以上 | 可有发热，程度相对轻 | 多数无发热 | 一般无发热 |
| 常见诱因 | 足癣、皮肤破损 | 伤口、溃疡、免疫力低下 | 静脉曲张、输液、外伤 | 静脉高压 |
| 首诊科室 | 皮肤科、外科 | 皮肤科、外科 | 血管外科 | 皮肤科、血管外科 |

丹毒和蜂窝织炎最容易混。2025 年发表于《Biomedicines》的综述指出，两者的关键区别在于丹毒**边界清晰、进展更快**，蜂窝织炎**边界弥漫、起病相对较慢**（Jaskóła-Polkowska 等）。

还有一个容易被忽略的点：**淤积性皮炎本身可以长得很像蜂窝织炎**，尤其是两条腿同时发红的时候。上述综述明确提醒，静脉淤滞性皮炎可模拟蜂窝织炎的表现。这也是为什么医生有时需要结合血常规、炎症指标甚至影像来判断，而不是只看一眼。

> 一个实用判断：**单侧、边界清楚、来得急、伴高热寒战**，要优先想到感染；**双侧、边界模糊、以痒为主、没有明显发热**，更像淤积性皮炎。但最终判断必须交给医生。

## 三、出现这些信号，不要在家观察

丹毒起病急。腾讯医典的描述是：患者常先出现高热、寒战、头痛、恶心，体温可升至 39℃ 以上，随后局部出现水肿性红斑，表面发紧发亮，可迅速向四周扩大。

以下情况建议尽快就医，其中前几条属于需要急诊处理的范围：

| 信号 | 说明 |
|---|---|
| 高热不退 | 体温持续 39℃ 以上，或退热药效果差 |
| 红斑快速扩大 | 几小时内范围明显变大，边缘向外推进 |
| 出现水疱、大疱 | 提示炎症较重，皮肤屏障进一步受损 |
| 皮肤发黑、坏死 | 提示可能存在更深的组织感染 |
| 患肢发凉、麻木、感觉异常 | 需排除动脉供血问题或筋膜室压力升高 |
| 精神差、意识模糊、呼吸急促、血压下降 | 警惕脓毒症与感染性休克，须立即急诊 |
| 糖尿病、长期用激素或免疫抑制剂、肾病综合征、高龄 | 这类人群感染后进展更快，就医门槛应更低 |

《Biomedicines》那篇综述列出的丹毒并发症包括菌血症、脓毒症、心内膜炎、脓肿，严重时可出现坏疽。这些并发症并不常见，但它们解释了为什么"腿上红一块"值得认真对待。

## 四、医生会怎么处理？这四件事别自己做

### 1. 抗生素要足量足疗程，不能"不烧了就停"

丹毒的首选治疗是抗感染。青霉素类是常用选择，青霉素过敏者由医生评估后更换方案。北京协和医院皮肤科孙秋宁主任医师的公开科普给出的口径是：**抗生素疗程通常为 10~14 天**，症状缓解后不能自行停药，否则容易复发。

> **抗生素是处方药。用不用、用哪种、用多久，必须由医生评估后决定，不可自行购买服用，也不可自行加量、减量或提前停药。**

### 2. 把腿抬高，减少下垂

卧床休息、抬高患肢是丹毒的基础处理之一。抬高有助于减轻肿胀，也能减少局部血液淤滞。坐位时把脚搭在小凳上，比一直垂着腿要好。

### 3. 急性期不要热敷、不要按摩、不要挤压

热水泡脚、热敷、按摩仪、刮痧，这些做法在急性感染期都可能帮倒忙。热敷会让局部血管扩张、渗出增加；按摩和挤压则可能推动细菌沿淋巴管扩散。**在红肿热痛没有消退之前，这些操作都应当停掉。**

### 4. 急性感染期不要穿弹力袜

这一点最容易被忽略。压力治疗相关专家共识把**拟加压部位的感染、蜂窝织炎**列为禁忌证。原因很直接：在感染尚未控制时外加压力，可能加重局部疼痛，也不利于炎症消退。

正确的顺序是：**先控制感染，等红肿热痛消退，再由血管外科医生评估是否可以恢复压力治疗。** 弹力袜在这里的角色始终是物理干预和辅助措施，它不能替代抗生素，也不能替代必要时的静脉手术。

## 五、为什么总是复发？关键是打破这个循环

丹毒有一个让人头疼的特点：**好了还会再来，而且常常还在原来的位置。**

《Biomedicines》2025 年那篇综述汇总的数据是：门诊患者第一年内复发率约 11%，住院患者三年内复发率最高可达 46%；复发多数发生在与原发部位相同的解剖位置，有研究报道这一比例最高可达 95%。综述还指出，丹毒康复后**不产生持久免疫**，目前也**没有疫苗**。

复发的核心机制是一个双向的恶性循环：

**每次丹毒发作都会进一步损伤淋巴管 → 淋巴回流变差，形成或加重淋巴水肿 → 水肿让局部组织营养和氧合变差、慢性炎症持续 → 皮肤更容易破损、细菌更容易定植 → 再次发作。**

所以，只盯着"这次的红肿消没消"是不够的。要降低复发，得同时处理三件事。

### 第一件：把"入口"堵上

- **足癣和甲癣要规范治疗。** 趾缝潮湿、脱皮、发白、皲裂，都是细菌的藏身处。抗真菌治疗需要足够疗程，不能"不痒了就停"。
- **皮肤要保湿。** 小腿干燥皲裂在秋冬尤其常见，洗完澡趁皮肤微湿时涂抹润肤剂，比反复抓挠有用。
- **小伤口要处理。** 蚊虫叮咬、擦伤、倒刺，先用清水和肥皂清洁，保持干燥，必要时覆盖；不要用指甲去抠。
- **趾甲剪平，不要深挖甲沟。**

### 第二件：把静脉压力降下来

- **压力治疗**：在医生评估后规范穿医用弹力袜，白天穿、睡觉脱。
- **抬高下肢**：休息时把腿抬到高于心脏的位置，每次 15~20 分钟，每天数次。
- **踝泵运动**：坐着或躺着时反复勾脚、绷脚，让小腿肌肉充当"第二心脏"。
- **控制体重、控制血糖、戒烟**：这三项在综述中被列为可改变的危险因素。
- **必要时评估手术**：如果超声提示明确的静脉反流或梗阻，血管外科医生会判断是否需要腔内治疗或手术。

关于压力治疗的效果，那篇综述引用了一项随机单中心试验：坚持穿戴分级压力袜的患者，复发风险显著下降（HR 0.23，95% 置信区间 0.09~0.59）；另一项小型试验中，压力治疗组复发率为 15%，单纯健康教育组为 40%。这些数字说明压力治疗在预防复发上有实际价值，但综述同时提醒，**外周动脉疾病、周围神经病变、压力材料过敏者禁用**，依从性差也会让效果打折。

### 第三件：反复发作者，由医生评估是否需要药物预防

对于一年内多次发作的人，医生可能会考虑长期小剂量抗生素预防。综述汇总的证据显示，青霉素 V 250 mg 每日两次、持续 12 个月，可使复发风险下降约 45%（PATCH I 试验：22% 对 37%，HR 0.55）。但综述也明确指出，**药物预防不用于首次发作，只用于反复发作者，且必须个体化权衡**；在合并慢性水肿、体重指数≥33、或既往 3 年内发作≥3 次的人群中，获益并不明显。

> 这一段提到的所有药物方案，都只是研究中的做法，**不构成用药建议。是否需要进行药物预防、用哪种药、用多久，必须由感染科或皮肤科医生评估，不可自行购买服用。**

## 六、日常防复发清单

把上面几节压缩成一张可以贴在冰箱上的清单：

| 频率 | 做什么 |
|---|---|
| 每天 | 洗脚后擦干趾缝；小腿涂润肤剂；坐久了起来走 5 分钟；睡前抬高下肢 15~20 分钟 |
| 每天 | 按医嘱穿弹力袜（急性感染期除外）；做 3~5 组踝泵 |
| 每周 | 检查一次双脚皮肤：有无脱皮、皲裂、水疱、小伤口、趾甲异常 |
| 每季 | 检查鞋袜是否挤脚；更换失去弹性的弹力袜 |
| 长期 | 控制体重、控制血糖、戒烟；足癣按疗程治疗 |
| 出现信号时 | 单侧红肿 + 发热 → 尽早就医，不泡脚、不按摩、不穿弹力袜 |

## 七、常见问题

### Q1：丹毒会传染给家人吗？

不会。腾讯医典的条目明确写明丹毒不会传染。它是细菌从患者自身的皮肤破损处侵入引起的局部感染，不需要隔离。

### Q2：丹毒和蜂窝织炎是一回事吗？

不是。丹毒主要累及真皮上层和淋巴管，边界清楚；蜂窝织炎累及更深的皮下组织，边界不清。两者的致病菌谱和治疗方案有重叠，但判断和用药强度需要医生根据范围、深度和全身症状来决定。

### Q3：红肿消了就能停抗生素吗？

不建议。症状好转不等于细菌已经清除。孙秋宁主任医师给出的疗程口径是 10~14 天，具体停药时间由医生决定。自行提前停药是复发的常见原因之一。

### Q4：有静脉曲张，需要平时吃抗生素预防丹毒吗？

不需要。药物预防只针对反复发作的患者，而且要在医生评估后使用。对大多数静脉曲张患者来说，**治足癣、护皮肤、降静脉压**才是更基础也更安全的预防方式。

### Q5：丹毒期间能穿弹力袜吗？

急性红肿热痛期不建议穿。感染部位加压属于压力治疗的禁忌情形。等感染控制、红肿消退后，再由医生评估恢复时间与压力等级。

### Q6：反复丹毒会把腿"毁掉"吗？

反复发作确实可能造成后果。每次感染都可能损伤淋巴管，逐渐形成淋巴水肿，皮肤变硬变粗，严重时出现象皮肿样改变。这也是为什么"反复发作"本身就是一个需要认真对待的信号，而不是忍一忍就过去的小毛病。

## 给静脉曲张患者的一句话总结

**腿上突然红一块、发烫、还发烧，先别当成"静脉曲张加重"，要想到感染的可能；一旦怀疑丹毒，尽快就医、足疗程抗感染，急性期不热敷、不按摩、不穿弹力袜；等感染控制住，再回头把足癣、皮肤和静脉压力这三件事管好，才是减少复发的正路。**

按重要性排一遍：**第一，识别信号**——单侧、边界清楚、来得急、伴发热，优先就医；**第二，规范治疗**——抗生素由医生开、按疗程用完；**第三，急性期做减法**——不泡脚、不按摩、不加压；**第四，长期做加法**——治足癣、勤保湿、穿弹力袜、抬腿、控体重；**第五，反复发作者**，请医生评估是否需要进一步检查静脉与淋巴回流。
