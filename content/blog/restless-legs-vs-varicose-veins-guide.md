很多人都有过这样的夜晚：白天腿没什么感觉，一躺到床上，小腿就开始发酸、发胀、发麻，像有虫子在爬，怎么放都不舒服。翻来覆去睡不着，只好下床走两圈，或者使劲蹬几下腿、捶一捶，症状才暂时消退；刚躺回去没多久，又开始难受。

遇到这种情况，多数人第一反应是"我是不是静脉曲张"。

但有一种专门的神经系统疾病，名字就叫**不宁腿综合征**（Restless Legs Syndrome，RLS），它的核心表现恰恰就是"夜里腿难受、必须动腿"。而且《中国不宁腿综合征的诊断与治疗指南（2021版）》在诊断标准里，**明确把"静脉曲张"列为需要排除的模仿因素之一**——也就是说，两者既容易混淆，又确实是不同的病。

这篇文章就来讲清楚：它们各自是什么、怎么区分、会不会同时存在，以及你该做什么、该挂哪个科。

## 一、先认识"不宁腿综合征"

### 它到底是什么

不宁腿综合征（又称 Willis-Ekbom 病）是一种**与睡眠相关的运动感觉性疾病**，属于神经内科的范畴。它的"不宁"，指的不是单纯想抖腿，而是一种**静坐不能、必须活动双腿才能缓解的内在冲动**。

患者用来形容这种感觉的词，往往很"奇怪"：

- 酸胀、沉重、紧绷
- 蚁走感（像虫子爬）
- 牵拉感、撕裂感、灼热感
- 说不清、描述不出来的"骨头里不舒服"

这些不适主要出现在**双侧小腿**，也可能累及大腿，少数人上肢甚至身体其他部位也会有。

### 中国指南的诊断标准：A、B、C 必须同时满足

《中国不宁腿综合征的诊断与治疗指南（2021版）》沿用了睡眠障碍国际分类第 3 版与 IRLSSG 国际标准，认为**只有同时满足以下三条，才可以诊断为 RLS**：

| 标准 | 内容 |
|---|---|
| **A. 核心表现** | 有迫切需要活动腿部的欲望，通常伴腿部不适感，或认为该欲望由腿部不适感引起；并且同时符合三个特征：① 症状在**休息或不活动**时（躺着、坐着）出现或加重；② **运动**可使症状部分或完全缓解（如行走、伸展腿部），至少活动时缓解；③ 症状**全部或主要发生在傍晚或夜间** |
| **B. 排除其他原因** | 上述症状不能由其他疾病或行为问题解释，例如**腿抽筋、姿势不适、肌痛、静脉曲张、下肢水肿、关节炎或习惯性踮脚** |
| **C. 功能受损** | 症状已经导致患者忧虑、苦恼、睡眠紊乱，或心理、躯体、社会、职业、教育、行为等方面的重要功能障碍 |

> 请注意 B 条：**"静脉曲张"被指南白纸黑字写进了需要排除的清单**。这正说明——夜里腿难受，不能想当然地都归给静脉曲张。

### 2014 年国际标准的五条（更细）

国际不宁腿综合征研究组（IRLSSG）2014 年修订的标准共五条，第 5 条就是"排除模仿者"：

1. 有活动双腿的强烈欲望，常伴（或被认为由之引起）腿部不适感；
2. 该欲望与不适感在休息或不活动时出现或加重；
3. 走动、伸展等活动能使其部分或完全缓解，**只要活动持续**；
4. 在傍晚或夜间加重，或仅在该时段出现；
5. 以上表现**不能单纯由其他疾病或行为状况解释**（如肌痛、**静脉瘀滞**、下肢水肿、关节炎、**腿抽筋**、体位不适、习惯性拍足）。

### 患病情况：中国人群并不算少见

指南给出的流行病学数据如下：

| 地区 / 人群 | RLS 患病率 |
|---|---|
| 欧美发达国家 | 5%~10% |
| 亚洲人群 | 0.1%~3.0% |
| 上海某街道 >50 岁人群 | 0.69% |
| 上海金山区两个社区成年人 | 1.4%（女性约为男性的 2 倍） |
| 青岛某镇 >18 岁人群 | 7.2% |

可以看得出：**不同地区差异很大，年龄越大越常见，女性多于男性**。

### 哪些人更容易得：原发 vs 继发

- **原发性（特发性）**：常有家族史，多在 45 岁前发病，可能与中枢神经系统铁代谢与多巴胺功能有关。
- **继发性**：多在 40 岁以后发病，常见于**铁缺乏**、**妊娠**、**慢性肾脏病/肾衰竭**、**糖尿病周围神经病变**、帕金森病等；**尼古丁、酒精、咖啡因，以及部分抗抑郁药、抗组胺药、抗精神病药**也可能诱发或加重症状。

> 其中**缺铁是最常见、也最容易干预的一个因素**——这也是为什么医生常常会给你开血常规和铁代谢的检查。

### 还有一个支持诊断的线索

**周期性肢体运动（PLMS）**：睡眠中不自主的、刻板的小腿抽动。它出现在约 **80%** 的 RLS 患者身上，但**不是诊断的必需条件**——有它支持诊断，没有它也不能排除。

## 二、静脉曲张和"不宁腿"，到底是什么关系？

### 它们本质上是两回事

- **下肢静脉曲张**：属于**血管的结构性问题**——静脉瓣膜关闭不全、静脉壁薄弱，血液回流不畅、淤积在小腿，静脉内压力升高。典型表现是青筋凸起、腿部沉重酸胀、脚踝水肿、皮肤色素沉着。
- **不宁腿综合征**：属于**神经系统的问题**——一种感觉运动障碍，核心是"静息时出现不适、活动才缓解"，与中枢铁代谢和多巴胺系统功能异常有关。

一个是"管道"的问题，一个是"神经信号"的问题。这也是它俩需要分开来看的原因。

### 但两者确实存在重叠

临床上，有不少患者**同时**存在静脉曲张和夜间腿部不适。多项研究观察到了这一现象：

| 研究 | 人群 | 结果 |
|---|---|---|
| Cureus 2019 回顾性研究 | 经超声证实存在下肢浅静脉反流者 | 约 **31.3%** 报告有 RLS 症状；接受射频消融/泡沫硬化剂治疗后，IRLS 评分平均下降约 **63%** |
| J Vasc Surg: Venous Lymphat Disord 2021 | 下肢静脉专科人群 | 有浅静脉反流者 RLS 症状报告率 **78.8%**，无浅静脉反流者 **45.7%**（p<0.001）；超声证实反流已纠正后，**85.9%** 报告 RLS 症状有主观改善 |
| J Vasc Interv Radiol（506 例） | 静脉专科门诊患者 | 报告 RLS 症状的 209 人中，**85%** 超声发现外侧皮下静脉丛（LSVP）异常；既无 RLS 也无夜间抽筋的 83 人中，仅 **2%** 存在该异常 |

> **必须说清楚的是：这些是"相关性"观察，不能直接等同于"静脉曲张导致了不宁腿"。**
>
> 目前医学界还没有定论——RLS 可能是与慢性静脉功能不全**同时出现**的一种表现，也可能静脉反流确实会通过组织缺氧等机制参与其中。这些研究的样本多来自静脉专科门诊，本身存在选择偏倚，**结论不能简单外推到所有静脉曲张人群**。

### 一个可能的解释

静脉曲张时，血液淤积在小腿、静脉压力升高，液体渗到组织间隙形成水肿，局部氧供下降。有一种推测是：**大脑"催促"你活动双腿，其实是下意识地想通过小腿肌肉泵，把淤积的血液挤回心脏**。

这也解释了为什么这类患者的夜间不适，有时在抬腿、穿医用弹力袜、改善静脉回流之后会好转——但这只是"部分患者""有时"，**不能保证，也不能替代正规诊疗**。

## 三、一张表分清：你的夜间腿难受更像哪一种？

| 鉴别点 | 更像静脉曲张相关 | 更像不宁腿综合征 |
|---|---|---|
| **核心感受** | 酸胀、沉重、发紧，像"腿里灌了铅" | "说不清的不舒服"+**强烈的活动冲动**（不动就难受） |
| **诱发状态** | 久站、久坐**之后**加重 | **一静下来、一躺下就发作或加重** |
| **缓解方式** | **抬高患肢**、平卧休息后减轻 | **必须走动、伸展、按摩**才能缓解；单纯躺着不动往往更难受 |
| **时间规律** | 傍晚、夜间加重，晨起最轻 | 傍晚/夜间加重，**深夜至凌晨达高峰** |
| **抬腿试验** | 抬高后数小时内多能减轻 | 抬腿本身不缓解，甚至因"更加静止"而更难受 |
| **伴随体征** | 青筋凸起、脚踝水肿、皮肤发黑发痒、溃疡 | 多无血管外观改变；可能伴睡眠中腿部抽动（PLMS） |
| **抽筋 vs 想动** | 可能是夜间小腿抽筋（肌肉强直性疼痛，持续数分钟） | 是"想动腿"的冲动，不一定是痛 |

> **实操小技巧**：如果你**抬腿、平躺一会儿就能舒服**，更偏向静脉问题；如果你**躺下就难受、必须起来走两步**，走动时缓解、停下又犯，那要高度怀疑不宁腿综合征，建议到**神经内科**评估，而不是只盯着血管。

### 特别注意：两者可以同时存在

指南在排除标准中也说明——**其他疾病可以与本症共存**，只是 RLS 的症状需要能与合并疾病的症状区分开。所以：

- 有静脉曲张 ≠ 一定不是 RLS；
- 有 RLS ≠ 静脉曲张就不需要管。

判断这件事，需要医生结合病史、体格检查和辅助检查来做，**不建议自己给自己下结论**。

## 四、如果更像静脉曲张：夜间能做的几件事

1. **抬高下肢**：休息或睡眠时把小腿垫高，高于心脏水平约 30°（大约一个枕头的高度），帮助静脉回流，减轻淤血与酸胀。
2. **白天穿医用弹力袜**：它是**物理干预手段**，通过外部压力辅助静脉回流、减轻下肢不适；**不能替代药物或手术**。具体压力等级、长度和型号，需要在专业指导下选择（合并下肢动脉疾病、糖尿病神经病变者要先评估）。
3. **踝泵运动**：睡前做几组勾脚—绷脚，激活小腿肌肉泵，把血液"挤"回去。
4. **避免久站久坐**：白天每小时起身活动几分钟，减少血液在下肢的淤积。

## 五、如果更像不宁腿：生活上先做这几件事

指南强调，**先评估并尽量消除可能加重症状的因素**，同时培养健康的睡眠习惯：

- **规律作息**：尽量每天在同一时间入睡和起床，避免睡眠剥夺（疲劳会让症状加重）。
- **减少刺激物**：尽量避免咖啡因、酒精、尼古丁，尤其**午后不要喝咖啡、浓茶**。
- **睡前拉伸与按摩**：睡前 1~2 小时做小腿拉伸、慢走，或轻轻按摩腿部。
- **温水放松**：睡前可用 38~40℃ 温水泡脚 10~15 分钟（注意防烫伤；合并糖尿病周围神经病变、下肢动脉供血不足者需谨慎）。
- **记录症状日记**：连续记 2 周——什么时候发作、什么姿势加重、怎么缓解、有没有在吃什么药。就诊时这份记录对医生很有价值。

> **关于用药，要特别强调**：RLS 的用药（包括补铁、多巴胺受体激动剂、α2δ 配体类药物等）**都属于处方治疗，必须由神经内科或睡眠专科医生评估后决定，不可自行购买服用，也不可自行加减量或停药。** 多巴胺类药物长期使用存在"症状恶化（augmentation）"的风险，突然停药也可能带来问题，**任何调整都必须在医生指导下进行**。

## 六、去医院可以查什么？

如果夜间症状每周出现 3 次以上、持续 3 个月，或者已经明显影响睡眠和白天状态，建议就医。可能涉及的检查包括：

| 方向 | 常见项目 | 目的 |
|---|---|---|
| **铁代谢** | 血常规、**血清铁蛋白**、转铁蛋白饱和度 | 排查最常见、最可干预的缺铁因素 |
| **基础病筛查** | 血糖/糖化血红蛋白、肾功能、电解质、甲功、维生素 B12、叶酸 | 寻找继发原因 |
| **血管评估** | **下肢静脉超声** | 判断有无静脉瓣膜反流、静脉曲张、血栓 |
| **神经评估** | 肌电图、神经传导速度 | 排查周围神经病变 |
| **睡眠评估** | 多导睡眠监测（PSG） | 观察周期性肢体运动，排除睡眠呼吸暂停等 |

> **该挂哪个科？** 以夜间"必须动腿"的不适为主，首选**神经内科**（部分医院设有睡眠医学中心）；以下肢青筋、水肿、沉重感为主，可先到**血管外科**做下肢静脉超声排查。**孕期女性出现这类症状，应先到妇产科就诊，由医生判断是否需要进一步转诊。**

## 七、常见问题解答

### Q1：夜里腿难受，是不是缺钙？

不一定，而且**多数情况不是**。缺钙更典型的表现是肌肉抽搐（也就是常说的抽筋）；而"酸胀、蚁走感、说不清的不舒服、必须动一动才舒服"这类症状，更符合不宁腿综合征或下肢静脉回流问题。想搞清楚，应查**铁代谢**和**下肢静脉**，而不是盲目补钙。

### Q2：穿医用弹力袜，能改善不宁腿吗？

不能一概而论。弹力袜是**物理干预手段**，针对的是**静脉回流问题**。如果这位患者的不适确实与静脉淤血有关，规律穿着可能有助于减轻腿部沉重和酸胀；但如果本质是原发性的不宁腿综合征，弹力袜**不能替代**针对病因的评估和治疗。**是否可以穿、穿什么压力等级，应由医生结合下肢动脉情况和神经病变情况来判断。**

### Q3：孕期腿难受、晚上睡不好怎么办？

孕期由于激素变化、血容量增加和子宫压迫，下肢不适和 RLS 症状都可能出现。**孕期任何症状的处理都建议先到妇产科就诊，由医生评估后决定方案**，不建议自行用药，也不建议自行购买保健品服用。

### Q4：老人夜里频繁踢腿、翻身多，是病吗？

可能是睡眠中的周期性肢体运动（PLMS），它常见于 RLS 患者，也可见于其他情况；同时，老年人的静脉功能、腰椎和神经问题也更常见。**建议到神经内科或睡眠专科就诊评估**，别简单当成"觉轻"。

### Q5：平时爱抖腿，是不是不宁腿综合征？

抖腿的原因很多，紧张、焦虑时的习惯性抖腿很常见。RLS 的关键不在于"抖"，而在于**静息时出现难以忍受的不适、活动后明显缓解、且傍晚或夜间加重**。如果你只是坐久了习惯性动动腿，没有上述规律，通常不必紧张。

## 给夜里睡不好觉的你一句话总结

1. **夜里腿难受，先别急着都归给静脉曲张。** 有一种专门的神经系统疾病叫"不宁腿综合征"，指南明确把静脉曲张列为需要排除的模仿因素。
2. **记住一个关键区别**：抬腿平躺就舒服的，多偏静脉问题；躺下就难受、必须走两步才缓解的，要怀疑不宁腿。
3. **两者也可能同时存在**，判断需要医生结合病史和检查，不建议自行下结论。
4. **就医方向**：以"必须动腿"为主 → **神经内科**；以青筋、水肿、沉重为主 → 先做**下肢静脉超声**；孕期 → **妇产科**。
5. **弹力袜是物理干预与辅助措施，不能替代药物或手术**；涉及用药和手术，**必须由医生评估，不可自行服用或决定。**
