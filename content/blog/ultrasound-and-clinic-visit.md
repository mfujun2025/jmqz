## 为什么"看对科、查对项"这么重要

很多人发现腿上青筋凸起，第一反应是"要不要紧""该找谁看"。常见的两种做法都不太理想：

一种是**拖着不看**——觉得不疼不痒，忍忍就过去了。下肢静脉疾病是**随年龄增长而加重的进展性疾病**，拖延的代价是病变从"只是难看"发展到水肿、皮肤色素沉着，甚至静脉性溃疡。

另一种是**看错科、查错项**——跑到皮肤科治湿疹、到骨科治腿酸，或者只做了个普通体检，没查血管，来回折腾几个月。

这篇文章就把三件事说清楚：**该挂哪个科、去之前准备什么、超声报告单怎么看**。

> 需要先明确一点：本文讲的是"就医流程与报告常识"，不是自我诊断工具。任何检查结果的解读和后续方案，都必须由医生面诊判断。

## 一、该挂哪个科

### 1. 首选血管外科

下肢静脉曲张是**血管系统**的疾病，核心问题是静脉瓣膜功能不全导致血液反流、静脉压力升高。因此**首选血管外科**。

血管外科的优势在于：

- 能做下肢静脉超声并亲自解读（很多医院超声报告由超声科出，血管外科医生会结合体位、诱发动作复看）
- 能开展从压力治疗到微创手术的完整方案
- 能判断是原发性还是继发性（比如髂静脉压迫综合征、深静脉血栓后综合征）

### 2. 没有血管外科怎么办

部分医院（尤其是基层医院）没有独立血管外科，可以退而选择：

| 情况 | 可选科室 |
|---|---|
| 一般下肢静脉曲张，医院无血管外科 | 普通外科 |
| 已出现湿疹、色素沉着、溃疡等皮肤并发症 | 皮肤科先控制炎症，再由血管外科处理病因 |
| 孕期出现下肢静脉曲张或水肿 | 妇产科 |
| 儿童/青少年先天性静脉发育异常 | 小儿外科 |
| 突发单侧下肢明显肿胀、剧痛，怀疑急性血栓 | **急诊科**（不要等门诊） |
| 下肢水肿合并肾病综合征等全身疾病 | 先看肾内科控制原发病，再由血管专科协同 |

> **特别提醒**：如果出现**单侧腿突然肿胀、发硬、疼痛、皮温升高**，这可能是急性下肢深静脉血栓的表现，属于急症，应立即到急诊科就诊，**不能自行按摩**。

## 二、就诊前要准备什么

准备充分能显著提高一次就诊的效率。建议带上这几样：

### 1. 症状"时间线"记录

医生最需要的不是"我腿不舒服"，而是具体信息。就诊前可以按这个清单理一遍：

- **什么时候开始的**？几个月还是几年
- **什么时候加重**？久站后？下午？月经期？孕期
- **有没有这些伴随症状**：酸胀、沉重、夜间抽筋、瘙痒、踝部水肿
- **有没有危险信号**：单侧突发肿胀、皮肤变硬变色、破溃
- **职业情况**：每天站立/久坐多久
- **家族史**：父母、兄弟姐妹有没有静脉曲张
- **既往史**：有没有得过深静脉血栓、做过手术、是否在服用抗凝药
- **是否怀孕或在哺乳期**
- **既往检查报告**：之前做过的超声、化验单、病历本

### 2. 穿着要方便暴露下肢

医生需要**站立位**观察静脉隆起、迂曲程度，以及皮肤改变。建议：

- 穿**宽松裤装或裙子**，避免紧身牛仔裤
- 穿方便脱的鞋子
- 就诊当天**不要刻意穿弹力袜**（除非医生要求），因为医生需要看到自然状态下的静脉

### 3. 记下想问医生的问题

临床门诊时间有限，提前写下来不容易漏。可以参考：

- 我的情况属于 CEAP 分级第几级？
- 需要做哪些检查？超声要复查吗？
- 现在需要穿弹力袜吗？压力等级多少？
- 需要用药吗？需要手术吗？
- 多久复查一次？

## 三、下肢静脉超声：为什么它是首选检查

### 1. 传统物理检查只能做初筛

你可能听过这几个名字：**Trendelenburg 试验（大隐静脉瓣膜功能试验）**、**Perthes 试验（深静脉通畅试验）**、**Pratt 试验（穿通静脉瓣膜功能试验）**。

它们靠止血带和体位变化来判断瓣膜功能，成本低、可门诊完成，但**有明显局限**：这类物理检查无法准确定位反流的具体位置，也不能说明静脉曲张是原发性还是继发性，因此**只能作为初步筛查，不能作为诊断和指导治疗的依据**。

### 2. 彩超是首选，且是国际指南推荐

**彩色多普勒超声（Duplex Ultrasound）**是目前评估下肢静脉疾病的首选检查，也是国内外指南的一致推荐。它的特点：

- **安全无创**：无辐射、无造影剂、可重复
- **能明确两件事**：静脉有没有**阻塞**、有没有**反流**
- **能定位**：反流来自大隐静脉、小隐静脉、穿通静脉还是深静脉
- **能定量**：测量反流时间和静脉内径

《中国慢性静脉疾病诊断与治疗指南》（2019）明确指出，血管多普勒超声是静脉疾病**首选的辅助检查手段**；美国血管外科协会（SVS）、美国静脉论坛（AVF）等 2022 年发布的指南中也将其列为最高级别推荐。

> 检查时的关键要求：**站立位**（或不能站立时坐位、反 Trendelenburg 位），配合 Valsalva 动作或远端挤压/充气袖带放气来诱发反流。体位和诱发动作不到位，结果会失真。

### 3. 超声主要看哪些内容

一份合格的静脉超声报告通常包含以下信息：

| 检查内容 | 说明 |
|---|---|
| 深静脉是否通畅 | 股总静脉、股静脉、腘静脉有无血栓或阻塞 |
| 深静脉有无反流 | 股总、股、腘静脉反流时间 |
| 浅静脉主干情况 | 大隐静脉、小隐静脉各节段内径与反流 |
| 属支静脉 | 前/后副大隐静脉等有无反流 |
| 穿通静脉 | 有无反流、内径大小 |
| 解剖变异 | 主干走行是否异常（影响手术方案） |
| 静脉瘤样扩张 | 有无局限性扩张 |

## 四、报告单上的"反流时间"怎么看

这是患者最容易看不懂、也最关键的一个指标。反流时间越长，代表瓣膜关闭越差、血液倒流越严重。

### 1. 诊断标准（反流时间阈值）

| 静脉部位 | 功能不全的诊断标准 |
|---|---|
| 股总静脉、股静脉、腘静脉（深静脉） | 反流时间 **> 1 秒** |
| 大隐静脉、小隐静脉等浅静脉 | 反流时间 **> 0.5 秒** |
| 穿通静脉 | 反流时间 **> 0.5 秒**，且内径 **≥ 3.5 mm** |

这组阈值来自《中国慢性静脉疾病诊断与治疗指南》以及国际（美国 SVS/AVF、欧洲 ESVS）指南，国内外基本一致。部分欧美文献对穿通静脉也采用 0.35 秒作为界值，实践中以所在医院和检查规范为准。

### 2. 反流严重程度的分级

除了"有没有反流"，报告有时还会给出严重程度：

| 反流时间 | 程度判断 |
|---|---|
| 0.5~1.0 秒 | 可诊断有反流 |
| ≥ 1.0 秒且 < 2.0 秒 | 轻度反流 |
| ≥ 2.0 秒且 < 3.0 秒 | 中度反流 |
| ≥ 3.0 秒 | 重度反流 |

> **重要提醒**：反流时间只是一个**定性/半定量**指标，受操作者技术、患者体位、诱发动作是否标准、设备精度等多重因素影响。而且反流时间的长短**并不直接决定手术方式的选择**。所以不要自己拿着报告单上的秒数去"对标"严重程度，一定要听医生的综合判断——医生还会结合反流速度、静脉内径、症状和 CEAP 分级一起看。

### 3. 报告中常见的其他缩写

- **SFJ / SPJ**：隐股交界 / 隐腘交界，是反流最常发生的"源头"位置
- **GSV / SSV**：大隐静脉 / 小隐静脉
- **C** 开头如 **C2、C3**：这是 CEAP 临床分级，向医生确认自己属于哪一级最直接

## 五、超声之外，什么情况要做别的检查

大多数下肢静脉曲张，做一次下肢静脉超声就够了。但在特定情况下，医生会加做以下检查：

| 检查 | 什么时候需要做 |
|---|---|
| **D-二聚体** | 怀疑急性深静脉血栓时的筛查。**阴性预测值可达 97%~99%**，即结果正常基本可排除急性 DVT；但阳性不代表一定是血栓（术后、感染、肿瘤、妊娠等都会升高） |
| **CT 静脉造影（CTV）** | 怀疑髂静脉、下腔静脉血栓；需同时评估腹部盆腔静脉；或合并肺栓塞需同步检查 |
| **磁共振静脉造影（MRV）** | 孕妇、碘造影剂过敏者；需评估复杂解剖或静脉阻塞 |
| **静脉造影** | 曾被认为是"金标准"，但属有创检查（需穿刺置管、注射造影剂），现已基本被超声替代，仅在超声结果矛盾或介入治疗前使用 |
| **体积描记检测** | 评估深静脉通畅性与反流性，用于部分分级患者的补充评估 |

> 这些检查都有各自的适应证和风险（辐射、造影剂过敏、有创操作等），**是否加做、做哪一项，须由血管外科医生根据你的具体情况评估决定**。

## 六、就诊与随访的常见问题

### Q1：超声检查前需要空腹吗？

一般**不需要空腹**。单纯下肢静脉超声不涉及空腹要求。如果医生同时安排了其他需要空腹的项目（如腹部超声、血脂血糖），才需要空腹。建议就诊前电话确认。

### Q2：做超声要多久？疼不疼？

通常 20~40 分钟，取决于病变复杂程度。检查本身**不疼**，只是探头在皮肤上滑动并配合体位变化和动作，有时需要医生用手挤压小腿或让你做 Valsalva 动作（憋气用力）来诱发反流。

### Q3：我已经有静脉曲张了，多久复查一次？

没有统一答案，取决于分级和治疗方式。一般规律是：

- **保守治疗（穿弹力袜）阶段**：遵医嘱定期复查，通常半年到一年一次
- **术后**：多数医生建议在术后 1 个月、3 个月、6 个月做超声复查，评估闭合效果和有无新发反流，之后每年一次
- **出现异常**：腿部突然肿胀、疼痛加剧、切口红肿渗液，立即复诊

具体复查节奏**以主诊医生的方案为准**。

### Q4：弹力袜能替代检查和治疗吗？

不能。医用弹力袜是**物理干预手段和辅助措施**，不能替代药物，也不能替代手术，更不能替代必要的影像学检查。它能帮助缓解症状、延缓进展，但不解决已经发生的瓣膜结构问题。

### Q5：药店推荐的"静脉曲张药"能自己买来吃吗？

**不建议**。治疗慢性静脉疾病的静脉活性药物（如七叶皂苷类、黄酮类等）属于处方管理范畴，需要医生根据你的分级、合并疾病、是否在服用抗凝药等综合判断。**须由医生评估，不可自行购买服用**。孕期、哺乳期女性尤其要避免自行用药。

### Q6：医生说"暂时不用治，先观察"，是不是不重视我？

不是。静脉曲张的治疗是有阶梯的：早期（C1~C2）以压力治疗+生活方式调整为主，达到手术指征（如明显反流、皮肤营养改变、溃疡）才考虑干预。"先观察"通常是合理的保守策略，但**要按约定复查，而不是不来了**。

## 给准备就诊的你一句话总结

腿上青筋凸起，**别拖、别猜、别自己下结论**。记住三条：

1. **挂血管外科**（没有就挂普通外科；孕期挂妇产科；突发单侧肿胀剧痛去急诊）
2. **做下肢静脉超声**——它是首选的、无创的、能定位反流源的核心检查
3. **带好症状时间线、宽松衣物和问题清单**，让一次门诊发挥最大价值

把"看对科、查对项"这一步走对，后面无论是穿弹力袜还是做微创，都会顺得多。

> 本文仅供健康科普参考，不构成诊疗建议。如有相关症状，请及时到正规医院血管外科就诊。孕期或哺乳期相关不适请到妇产科就诊，具体方案以医生面诊意见为准。
